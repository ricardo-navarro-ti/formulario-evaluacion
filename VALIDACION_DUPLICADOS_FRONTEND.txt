  🎯 ¿QUÉ SE IMPLEMENTÓ?
═══════════════════════════════════════════════════════════════════════════════

✅ Validación TEMPRANA de duplicados
   • Se ejecuta al presionar "Calcular Nota Final"
   • Evita que el usuario complete toda la evaluación solo para descubrir al final
     que ya está duplicada

✅ Doble validación (frontend + backend)
   • Frontend: Verifica ANTES de calcular la nota
   • Backend: Verifica ANTES de guardar en Google Sheets
   • Esto garantiza protección en ambos niveles

═══════════════════════════════════════════════════════════════════════════════
  🔧 FUNCIONAMIENTO TÉCNICO:
═══════════════════════════════════════════════════════════════════════════════

1. Usuario selecciona grupo y evaluador
2. Usuario completa todos los criterios
3. Usuario presiona "Calcular Nota Final"
4. 🔍 Sistema consulta Google Sheets vía JSONP
5. 🔎 Compara grupo + evaluador con registros existentes (case-insensitive)
6. ⚠️ SI YA EXISTE:
   → Muestra: "Ya existe una evaluación de '[evaluador]' para '[grupo]'."
   → NO permite calcular la nota
   → NO habilita el botón "Guardar"
7. ✅ SI NO EXISTE:
   → Calcula la nota normalmente
   → Habilita el botón "Guardar"

═══════════════════════════════════════════════════════════════════════════════
  📝 CÓDIGO AGREGADO (index.html):
═══════════════════════════════════════════════════════════════════════════════

Nueva función: verificarDuplicado(grupo, evaluador, callback)
  • Consulta todos los registros existentes vía JSONP
  • Compara grupo y evaluador (ignora mayúsculas/minúsculas)
  • Retorna true si existe duplicado, false si no

Modificación: calcularNota()
  • Ahora verifica duplicados ANTES de calcular
  • Muestra mensaje "🔍 Verificando duplicados..." mientras consulta
  • Si encuentra duplicado: muestra error y termina
  • Si no encuentra: calcula nota normalmente

═══════════════════════════════════════════════════════════════════════════════
  ✅ FLUJO COMPLETO DE VALIDACIONES:
═══════════════════════════════════════════════════════════════════════════════

Al presionar "Calcular Nota Final":
1️⃣ ¿Grupo seleccionado? → NO: Error "Falta completar el campo 'Nombre del Grupo'"
2️⃣ ¿Evaluador seleccionado? → NO: Error "Falta completar el campo 'Evaluador/a'"
3️⃣ ¿Todos los criterios evaluados? → NO: Error "Faltan X criterio(s) por evaluar"
4️⃣ ¿Ya existe evaluación de este evaluador para este grupo? → SÍ: Error "Ya existe una evaluación..."
5️⃣ ✅ TODO OK → Calcula nota y habilita botón "Guardar"

Al presionar "Guardar":
6️⃣ Backend verifica nuevamente (por seguridad)
7️⃣ ✅ Guarda en Google Sheets
