⚠️ IMPORTANTE: El archivo "apps-script.js" NO se actualiza automáticamente.
   Debes copiarlo manualmente a Google Apps Script siguiendo estos pasos:

┌─────────────────────────────────────────────────────────────────────────────┐
│ PASO 1: Abrir Google Apps Script                                           │
└─────────────────────────────────────────────────────────────────────────────┘

1. Abre tu Google Sheet de evaluaciones
2. Menú: Extensiones → Apps Script
3. Se abrirá el editor de código

┌─────────────────────────────────────────────────────────────────────────────┐
│ PASO 2: Copiar el nuevo código                                             │
└─────────────────────────────────────────────────────────────────────────────┘

1. En VS Code, abre el archivo: apps-script.js
2. Selecciona TODO el contenido (Ctrl+A)
3. Copia (Ctrl+C)

┌─────────────────────────────────────────────────────────────────────────────┐
│ PASO 3: Pegar en Google Apps Script                                        │
└─────────────────────────────────────────────────────────────────────────────┘

1. En el editor de Google Apps Script, selecciona TODO (Ctrl+A)
2. Pega el nuevo código (Ctrl+V) - reemplazará todo
3. Guarda (Ctrl+S o icono 💾)

┌─────────────────────────────────────────────────────────────────────────────┐
│ PASO 4: Crear nueva versión (CRÍTICO)                                      │
└─────────────────────────────────────────────────────────────────────────────┘

⚠️ SIN ESTE PASO, LOS CAMBIOS NO SE APLICARÁN EN PRODUCCIÓN ⚠️

1. Clic en el botón azul "Implementar" (arriba a la derecha)
2. Selecciona "Administrar implementaciones"
3. Clic en el ícono "✏️ Editar" de la implementación activa
4. En "Versión" selecciona "Nueva versión"
5. Clic en "Implementar"
6. Cierra la ventana emergente
